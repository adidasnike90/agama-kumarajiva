# 信达雅工作法（本项目）

优先级：**信 > 达 > 雅**。

## 信 = 对巴利／梵本之义，不是对求那跋陀罗之字

求那跋陀罗《杂阿含》常被评为生硬、欧化语序、义理有时含混。因此：

| 层 | 角色 |
|----|------|
| 巴利 SN（及梵本残卷） | **义理主裁判**（信） |
| 可靠现代译（Sujato / Bodhi / Patton 等） | 辅助理解平行 |
| 求那跋陀罗汉译 T99 | **定位与术语参考**；拙译、歧义处可据平行改正 |
| 罗什风汉语 | 表达层（达 + 雅） |

### 操作细则

1. 有清晰 SA↔SN 平行时：罗什风正文应传达**平行所显的早期教理**；若汉译与平行冲突或严重碍读，从平行，并在 `notes` 写「据 SNxx 校正／澄清」。
2. 汉本有、巴利无的内容：可保留为汉传异读，notes 标明「汉本特有，平行未见」。
3. 无可靠平行：不臆造；依汉译作有限度雅化，confidence=medium/low。
4. **V1** 研究译注本（大正卷序）；**V2** 研究译注本（经序重排）另册（非改掉 V1），见 [V2_ORDER.md](V2_ORDER.md)。本阶段（译笔）只做**语义层**信达雅。
5. 禁大乘／禅宗后出词：见 `glossary/forbidden_mahayana.txt`。

## 达

- 罗什风：古典汉语顺读，因果清楚。
- 白话：与罗什风**逐段对照**，开经结经不省；冷静，不鸡汤。

## 雅

- 四言节奏、删繁就简、意译优先。
- 例：`欲令如是、不令如是` → `得大自在` / `不得自在`（义据无我论证，辞采罗什风）。
- 雅服务于对印度本义之信，不是服务于「尽量像汉译原文」。
