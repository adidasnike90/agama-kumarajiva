# V3 法义读本：原则论证

> **地位**：论证并约束第三部产品「法义读本」。  
> **成书**：`make v3-reader`／`make book-v3`（8 章 · 28 通读篇；篇题新拟、多经熔文）。  
> **关系**：不取代 [EDITION_PRINCIPLES.md](EDITION_PRINCIPLES.md) 下之 **V1／V2 研究译注本**；三者并行。

---

## 1. 问题：结集体裁与通读需求错位

《杂阿含经》（T99）及巴利《相应部》属于**相应结集（saṃyukta）**：按主题聚合短经，同型反复、略式（peyyāla）、「亦如是」链条极为常见。此体裁之功能是：

1. **便于记诵与检索**（同主题下多变奏）；  
2. **保留传统经目与引用锚点**；  
3. **便于与平行传统对勘**。

它**不是**为「一次顺读、获得连贯法义叙述」而设计的。

因此，当读者（尤其非文献学者）以读《金刚经》《心经》或连贯论书的习惯面对 T99／V1／V2 时，必然感到：

| 现象 | 文献学解释 | 通读体验 |
|------|------------|----------|
| 同题多经、仅改一两句 | 结集变奏／教学模组 | 重复、冗赘 |
| 「亦如是」略式 | peyyāla 记诵惯例 | 断裂、需跳读 |
| 开经结经公式反复 | 经轨程式 | 节奏拖沓 |
| 插入与卷次乖违 | 传本史问题 | 主题跳跃 |
| 五层对照排版 | 研究需求 | 注意力被拆散 |

**V1（大正卷序）**与 **V2（经序重排）**正确服务于文献与结构阅读；它们**不能、也不应**为通读而牺牲经号、平行与全覆盖。  
若仍要求「一口气读完而次序井然」，必须另立**第三种编辑目标**——不是把研究本「改得好看一点」，而是承认：**目标函数不同**。

## 2. 产品三分：三种诚实，而非三种真伪

| | V1 研究译注本（大正卷序） | V2 研究译注本（经序重排） | **V3 法义读本** |
|--|--------------------------|--------------------------|-----------------|
| 主问 | 「馆藏第几经说什么？」 | 「按相应结构怎么读？」 | 「早期法义如何连贯呈现？」 |
| 单元 | SA 1–1362 逐经 | 同左 + 学术序 | **篇章／法义单元**（自有章次） |
| 与 T99 经序 | 绑定 | 阅读序变，经号不变 | **不追求对应** |
| 重复同型经 | 全收 | 全收 | **可删并、可代表** |
| 五层对照 | 必备 | 必备 | **可省略**（或以附录追溯） |
| 文体 | 仿罗什风（经轨仍可见） | 同左 | **仿罗什风意译**；程式可大幅压缩 |
| 对「信」的操作 | 逐经对平行 | 逐经对平行 | **对法义单元所据平行集群负责** |

三分的伦理含义：

- 研究本回答**可核验性**；法义本回答**可理解性与可通读性**。  
- 二者不可互相冒充：法义本若仍自称「第 × 经全译」，即欺诈；研究本若强行删并同型经，即破坏引用链。

## 3. 「法义本」之名所承诺与不承诺

### 3.1 承诺

1. **以早期阿含／相应部教理为内容边界**（无常、苦、空、非我、缘起、道品、涅槃等），不以大乘／禅宗后出形上学改写。  
2. **以意译与篇章重组追求达与雅**：行文自然简练，主题推进清楚，减少无信息增量的重复。  
3. **编辑行为可追溯**：删并、代表、重排均有原则与（至少对内）出处表；学者可回指 SA／SN，普通读者不必面对。

### 3.2 不承诺（硬边界）

1. **不**声称鸠摩罗什曾译《杂阿含》，**不**声称「若罗什译阿含当如此」。罗什《金刚经》仅为**文体与删冗精神的参照**，非历史比附。  
2. **不**声称恢复「原始结集」或「唯一正确经序」。V3 之序是**教学法编排**，属编辑假说，不是文献复原。  
3. **不**取代 V1／V2，**不**改写研究本语料之经号体系。  
4. **不**把删并后的散文伪托为「大正某经全文」。

## 4. 信达雅在 V3 中的重新安置

项目总原则仍是 **信 > 达 > 雅**（见 [XIN_DA_YA.md](XIN_DA_YA.md)）。V3 改变的是**信的作用域**，不是放弃信。

### 4.1 信（作用域上移）

| | 研究本（V1／V2） | 法义本（V3） |
|--|-----------------|--------------|
| 信的对象 | **每一 SA 经**对平行所显之义 | **每一法义单元**对其所据**经群／平行群**之义 |
| 允许的操作 | 逐经改写，不删经 | 代表、合并、略去无增量变奏 |
| 禁止的操作 | 臆造无平行之新义 | 同上；且禁止用后出教理「补全」叙事 |

**论证**：相应结集中大量短经的信息增量接近于零（仅替换蕴处界之一、或仅改听者）。对通读者逐字保留全部变奏，并不增加「信」，只增加噪声。把信定义为「对法义单元负责」，是在结集体裁下对「信」的**类型匹配**，不是降低标准。

**约束**：每个法义单元必须能回答：「主要依据哪些 SA／SN（或经群）？若与平行冲突，取舍理由为何？」——即使正文不印五层对照，编辑层必须有答案。

### 4.2 达（升为显性目标）

通读本以**篇章连贯**为第一可读性指标：因果链、问答推进、主题闭环应在章内完成。  
开经「如是我闻」、结经流通等程式：保留**足够识别传统经轨**的少量标志即可，不必每节全套重复。

### 4.3 雅（意译合法化）

研究本已允许「欲令如是…」→「得大自在」一类意译。V3 将此推进为**默认策略**：优先义、气、节奏，而非与 T99 句位对齐。  
雅仍服务于早期法义之信，**不**服务于「读起来像大乘圆融」或「现代化心灵鸡汤」。

## 5. 编辑原则（可操作）

下列原则应能写成审稿清单；样章阶段即试用。

### P1 · 体裁诚实

正文版式与前言必须标明：**法义读本／通读编排**；与研究译注本区分。引用规范：不得仅写「SA_12」仿佛逐经全译；应写「法义读本·某篇，据 SA×／SN× 等缩写」或等价表述。

### P2 · 信息增量原则（删并之核心判准）

对同主题经群：

- **保留**：提供新命题、新譬喻、新抉择、新对机，或为该群最完整叙事者；  
- **可略**：仅替换五蕴／六处之一而无新义者；纯「亦如是」链中与已留文本同构者；  
- **代表制**：同型 N 经可收为「一文 + 说明同类尚有…」（说明可在章末小注或编辑附录）。

**禁止**：因「不好读」而删去**独有教理步骤**或**汉本／平行争议关键节点**——争议应压缩叙述，而非抹去。

### P3 · 篇章按法义逻辑，不按纸面卷次

建议（可修订）之高层骨架，对齐早期道次第之常见教学序，而非 T99 卷序，例如：

1. 闻持与正法住  
2. 蕴／处／界与无常苦空非我  
3. 缘起与十二支  
4. 食、漏、结、使  
5. 道品（念处、根、力、觉、道）  
6. 入流与沙门果  
7. 涅槃与无诤  

具体章名与收录范围在样章后锁定。**不**要求与 Anesaki／印顺卷次一一同构；可参考其主题分块，但目标是教学法，不是复原会编。

### P4 · 插入与非相应材料

阿育王传等 T99 插入（如 SA 604、640–641）及明显非早期相应经之叙事：**默认不入**法义通读正文。若收录，必须进「附录·传本史」并标明性质。

### P5 · 重建经（◇）政策

研究本中据平行最小补叙之 ◇ 经：V3 **不**以「补全 T99 略式」为义务。仅当该法义单元需要该义且他处无更佳完整文本时，方吸入并改写为通读句；仍须在编辑表注明来源为重建／平行。

### P6 · 语汇边界（与研究本相同）

继续禁用后期大乘／禅宗形上语汇（`glossary/forbidden_mahayana.txt`）。意译不等于改宗。

### P7 · 双轨追溯（对内强制，对外可隐）

维护 `v3_edition_map`（名称可定）：

| 字段 | 用途 |
|------|------|
| `v3_unit_id` | 法义单元 ID |
| `title_zh` | 章／节标题 |
| `source_sa_t99[]` | 主要依据之 SA 列表 |
| `source_sn[]` | 主要平行 |
| `edit_ops` | keep / merge / exemplify / omit / compress_frame |
| `rationale` | 一句理由 |

无此表，则 V3 不可发布——否则无法回答「信」的审计。

### P8 · 与罗什《金刚经》类比的限度

可学之处：删繁就简、意译求通、篇章气势连贯、少学究注疏打断。  
不可学之处：般若空性之经题与宗趣**不**迁移入阿含法义本；不可用《金刚经》的「应无所住」话头改写五蕴无我论证。类比止于**译笔与编辑美学**，不及**教理嫁接**。

## 6. 可能的反对意见与回应

### 反对 A：「删经就是不信。」

**回应**：信的对象若是「1362 个文献单元的全覆盖」，那是研究本的信。结集体裁下，全覆盖对通读者并不增加教理信息。V3 的信是「单元所据经群之义不被歪曲」；用编辑表保证可审计。二者标准不同，不是有无信。

### 反对 B：「不按经序就是伪经。」

**回应**：历代注疏、会编、选本、科判均重编排。伪经是**伪造出处或伪造作者**。V3 公开声明教学法编排、不伪托罗什、不伪托大正全文，则属**标明身份的选编意译**，不是伪经。

### 反对 C：「既有 V2 重排，何必 V3。」

**回应**：V2 只改变**阅读顺序**，不删同型重复，仍保留五层研究体例。V3 改变**收录粒度与行文策略**。重排解决「跳卷」；删并与意译解决「重复与不连贯」。问题不同。

### 反对 D：「意译会滑向现代化乱讲。」

**回应**：以 P6 语汇禁区 + 平行集群审义 + 编辑表审计三重约束。样章须经与研究本同一「早期教理」审读标准；信心不足处降 confidence 或不出 V3。

### 反对 E：「普通人应直接读研究本，不必迁就。」

**回应**：研究本已存在且公开；迁就通读并不关闭研究通道。拒绝法义本，等于假定「唯一正当读者是文献学者」——与项目「对照检验、亦供阅读」的初衷不全重合。

## 7. 与系列书名的关系（命名建议）

- **系列书名**仍可：杂阿含经·仿罗什风新译  
- **V3 正式名建议**：**法义读本**（或「通读本」）  
- **副题建议**：依早期教理重编之删定意译；不与大正经序对应  

避免再用「学术整理」等易被误读为「复原原典」的词；V3 尤其应避免「复原」「原貌」「罗什定本」等。

---

## 8. 成功标准（何谓原则被遵守）

发布前至少满足：

1. 前言用一页说清与 V1／V2 的差异及不承诺项；  
2. 存在完整 `v3_edition_map`，且抽检单元均可回指 SA／SN；  
3. 样章读者测试：非学者能连续阅读而不因同型重复中断；学者能据附录复核取舍；  
4. 无大乘／禅禁词；无「罗什译阿含／恢复原经序」表述；  
5. 网站若上线 V3，与研究本开关并列且标签不混淆。

---

## 9. 结论

**法义读本在原则上成立**，当且仅当：

1. 承认相应结集与通读需求的**体裁错位**；  
2. 把「信」从「逐经全收」上移为「对法义单元所据经群负责」，并以编辑表审计；  
3. 把删并、意译、篇章重排定义为**标明身份的教学法编辑**，而非文献复原或伪托译史；  
4. 与 V1／V2 **并行不互相冒充**。

在此约束下，追求「如罗什译《金刚经》般次序井然、行文简练」，是对雅与达的正当诉求，而不是对信的背叛。
